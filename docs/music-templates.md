# Hoverline song templates (Prototype 46)

132 templates: 95 in rotation, 37 retired (their codes still play), 3 new in Prototype 46, 40 revised from Eric's notes on the Prototype 45 previews, the rest changed only by the generator-wide fixes (no held pad under the drops except where Eric allowed it, no shaker, space in the mix). A template pins the style; the notes are written live from the tune's seed, so it plays differently every time but always in its own style. Paste an example code into Settings, Music, Tune.
