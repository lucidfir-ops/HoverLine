# samples/

Hoverline's recorded drums and instruments (Prototype 45): `manifest.json` lists every sound, kit and instrument, and
each `.bin` file is a pack of lossless FLAC recordings that the game downloads only when a tune uses it. The copy for
playing from a file carries the same packs as `.js` scripts. Licences and the original file of every sound are in
`CREDITS.md`. The game plays without this folder too, on the smaller recordings inside the page.
